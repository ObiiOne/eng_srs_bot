# Telegram SRS English Bot — MVP v0.2

Telegram-бот для изучения английских слов и выражений методом интервального
повторения. Пользователь сам создаёт пары «английское выражение → свой
перевод», бот автоматически организует их повторение и строго проверяет
воспроизведение.

Дополнительно: отдельный режим изучения **неправильных глаголов** по тому же
SRS-алгоритму, с отдельной сессией, отдельной статистикой и своим списком
глаголов, задаваемым JSON-файлом.

Реализация соответствует документам:

- `product_vision.md`
- `functional_spec.md`
- `technical_spec.md`

## Как это работает

### Пользовательские пары

1. **Добавление пары.** Пользователь вводит английское выражение и свой русский
   перевод. Создаётся пара и две **независимые** карточки: `EN → RU` и
   `RU → EN`. Дубликаты после нормализации отклоняются.
2. **SRS.** Каждая карточка живёт по лестнице `NEW → 1d → 3d → 7d → 14d →
   30d → ARCHIVE`. Ошибка откатывает на одну ступень. `ARCHIVE + correct`
   остаётся в архиве и получает следующую плановую проверку через 30 дней.
   Ошибка в архиве возвращает карточку в `14d`.
3. **Сессия.** В обычную сессию попадают **все** обязательные карточки
   (`due_at <= now`) без искусственного лимита, минимум одна архивная
   `EN → RU` и одна `RU → EN` (если доступны). Если обязательных меньше
   пяти, архив добирает сессию до пяти. Состав сессии фиксируется в БД,
   восстанавливается после перезапуска и истекает в конце локальных суток
   пользователя. Порядок карточек перемешивается случайно при создании
   сессии и сохраняется в `SessionCard.position`.
4. **Проверка.** Строгое сравнение с эталоном после технической нормализации
   (trim, сжатие пробелов, lower). Синонимы, опечатки и альтернативные
   переводы не принимаются.
5. **Раннее повторение.** Повторение уже просмотренных сегодня карточек
   без изменения SRS.
6. **Редактирование и удаление.** Редактирование сбрасывает обе карточки в
   `NEW`, история сохраняется. Удаление — логическое (`Pair.deleted_at`),
   исключает пару из обучения, сохраняя историю.

### Неправильные глаголы

Отдельный режим, изолированный от пользовательских пар.

1. **Список глаголов** задаётся файлом `data/irregular_verbs.json`:

   ```json
   [
     {"base": "do", "past": "did", "pp": "done", "ru": "делать"},
     {"base": "go", "past": "went", "pp": "gone", "ru": "идти"}
   ]
   ```

   При старте файл валидируется. Битый JSON, отсутствующие поля,
   дубликаты `base` — бот не стартует.

2. **Синхронизация.** При входе в раздел «Неправильные глаголы» бот
   синхронизирует список с БД:
   - недостающие глаголы создаются;
   - изменённые формы / переводы обновляются, SRS-прогресс сохраняется;
   - глаголы, удалённые из JSON, помечаются `is_orphaned` — они
     продолжают учиться до архива, но в архиве больше не подмешиваются в
     сессии.

3. **Формат вопроса.**
   - `EN → RU`: показывается `do did done`, ожидается `делать`.
   - `RU → EN`: показывается `делать`, ожидается `do did done`.

4. **Проверка ответа** — строгая, но с гибкими разделителями:
   `do, did, done` = `do/did/done` = `do did done`. Порядок форм обязателен,
   опечатки и другие формы (`doing`) не принимаются.

5. **Сессия глаголов** — полностью отдельная от пользовательской:
   `StudySession.session_type = "VERB"`. Одновременно у пользователя
   может быть активна только одна сессия — либо обычная, либо по
   глаголам.

6. **Статистика глаголов** — отдельный экран, считает только verb-карточки.

7. **Раннее повторение глаголов** — отдельная кнопка, работает по тем
   же правилам, что и для слов.

## Схема данных

Ключевые поля, добавленные для режима глаголов:

- `Pair.source` — `USER` или `VERB`;
- `Pair.verb_base` — базовая форма глагола (для идемпотентной синхронизации);
- `Pair.is_orphaned` — глагол удалён из JSON, но пара осталась в БД;
- `StudySession.session_type` — `USER` или `VERB`.

Осиротевший глагол:

- до архива — продолжает учиться как обычно;
- в архиве — не подмешивается в сессии.

## Резервное копирование

```bash
cp srs_bot.db srs_bot.db.bak
```

Перед обновлением кода рекомендуется отдельная копия:

```bash
cp srs_bot.db "srs_bot.before-update.$(date +%F_%H-%M).db"
```

Автоматический бэкап через cron (пример):

```
# Ежедневный бэкап в 04:00
0 4 * * * mkdir -p /root/backups && cp /root/eng_srs_bot/srs_bot.db /root/backups/srs_bot.$(date +\%F).db

# Ротация: удалять бэкапы старше 30 дней в 04:30
30 4 * * * find /root/backups -name 'srs_bot.*.db' -mtime +30 -delete
```

## Порядок деплоя

1. Локально: `pytest` — убедиться, что всё зелёное.
2. Бэкап БД на сервере:

   ```bash
   ssh root@<server> \
     "cp /root/eng_srs_bot/srs_bot.db \
        /root/backups/srs_bot.before-verbs.$(date +%F_%H-%M).db"
   ```

3. Rsync с исключениями:

   ```bash
   rsync -avz --delete \
     --exclude='.venv' \
     --exclude='__pycache__' \
     --exclude='*.pyc' \
     --exclude='.DS_Store' \
     --exclude='.git' \
     --exclude='.env' \
     --exclude='*.db' \
     --exclude='*.sqlite' \
     --exclude='*.sqlite3' \
     --exclude='.pytest_cache' \
     ./ root@<server>:/root/eng_srs_bot/
   ```

4. Проверить наличие `data/irregular_verbs.json` на сервере.
5. `systemctl restart srsbot`.
6. Проверить логи:

   ```bash
   journalctl -u srsbot -n 50 --no-pager
   ```

7. Проверить схему после автомиграции:

   ```bash
   sqlite3 /root/eng_srs_bot/srs_bot.db "PRAGMA table_info(pairs);"
   sqlite3 /root/eng_srs_bot/srs_bot.db "PRAGMA table_info(study_sessions);"
   ```

   Ожидаемые новые колонки: `source`, `verb_base`, `is_orphaned`,
   `session_type`.

8. Проверить в Telegram:

   - «📖 Неправильные глаголы» → меню глаголов;
   - «▶️ Учить глаголы» → сессия, в шапке `ГЛАГОЛЫ`;
   - ответ `do, did, done` на `делать` → правильно;
   - ответ `did do done` → ошибка;
   - «📊 Статистика глаголов» → отдельные цифры;
   - «📊 Статистика» → только слова.

## Разработка

### Добавление глагола

Отредактировать `data/irregular_verbs.json`:

```json
{"base": "teach", "past": "taught", "pp": "taught", "ru": "учить"}
```

Перезапустить бота. При входе в раздел глаголов изменения подтянутся
автоматически (sync).

### Удаление глагола

Убрать строку из JSON. Перезапустить бота. При следующем входе в раздел
глаголов пара будет помечена `is_orphaned`. Она доучивается до архива,
дальше в сессии не подмешивается.

### Изменение перевода

Отредактировать поле `ru` в JSON. SRS-прогресс карточек сохраняется.
